🗺️ 知识图谱可视化

展示维修知识图谱的整体结构，包括飞机型号、事故类型和制造商之间的关联关系。

💡 拖动节点可调整位置，滚轮缩放

按飞机型号分类展示，显示各型号的事故分布和关联制造商。

按事故类型分类展示，显示各类事故涉及的飞机型号和频率。

按制造商分类展示，显示各制造商的飞机型号和事故统计。

展示飞机型号与事故类型的关联热力图，颜色越深表示关联越强。

🎯 向量空间可视化

每条航空维修记录经过 AI Embedding 模型转换为向量，再用 t-SNE 降维到 2D 平面绘制散点图。

  • 每个点 = 一条维修记录
  • 距离近的点 = 语义相似的记录
  • 颜色 = 按数据来源分组（FAA/MaintNet）
