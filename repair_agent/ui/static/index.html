🗺️ 知识图谱可视化

展示 Neo4j 中存储的航空维修知识图谱，包括飞机型号、事故类型和制造商之间的关联关系。

🎯 向量空间可视化

每条航空维修记录经过 AI Embedding 模型转换为向量，再用 t-SNE 降维到 2D 平面绘制散点图。

  • 每个点 = 一条维修记录
  • 距离近的点 = 语义相似的记录
  • 颜色 = 按数据来源分组（FAA/MaintNet）
