## 3. 数据流

### 3.1 诊断流程

```python
# 用户输入
description = "手机屏幕碎裂，触摸不灵敏"
image_path = "photo.jpg"  # 可选

# Step 1: RAG检索（Qdrant）
knowledge = rag_tool.search(query=description, limit=5)
# → 找到5条相似维修记录

# Step 2: 图片分析（MiMo-V2.5，如果有图片）
if image_path:
    image_analysis = vision_llm.invoke([{
        "role": "user",
        "content": [
            {"type": "image_url", "url": "data:image/jpeg;base64,..."},
            {"type": "text", "text": "分析这张故障照片"}
        ]
    }])

# Step 3: LLM诊断（DeepSeek）
diagnosis = llm.invoke([{
    "role": "user",
    "content": f"故障描述: {description}\n参考案例: {knowledge}\n图片分析: {image_analysis}"
}])

# Step 4: 损伤评估
severity = assess_severity(diagnosis)  # 轻微/中等/严重

# Step 5: 方案推荐
solution = recommend_solution(diagnosis)

# Step 6: 工单生成
work_order = generate_work_order(description, diagnosis, solution, severity)
```

